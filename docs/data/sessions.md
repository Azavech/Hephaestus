# Session storage

files:
- HephaestusKit/Sources/HephCore/YAML/SessionFile.swift
- HephaestusKit/Sources/HephHost/Claude/SessionArchive.swift

---

The Main stores each Claude session of a project in `<project root>/.hephaestus/sessions/`:

```
.hephaestus/sessions/<id>.yml      metadata
.hephaestus/sessions/<id>.jsonl    events, one JSON object per line
.hephaestus/sessions/<id>/         files attached to the user's messages
```

`SessionService` ([claude/cli.md](../claude/cli.md)) runs the sessions: it creates them, turns the CLI output into
events and keeps the live statuses. This doc defines what is stored and how `SessionArchive` writes and reads it.

## Session id

- A session id is a `UUID` (`SessionInfo.id`, [protocol/types.md](../protocol/types.md)), generated by the Main when
  the session is created.
- File and folder names, and the id given to the Claude CLI (`--session-id`, `--resume`), use its lowercase form
  `id.uuidString.lowercased()`, for example `3f2b8c1e-9a4d-4f6b-8e2a-1c5d7e9f0a2b` (`SessionFile.fileStem(_:)`).
- Inside the files, Yams and the wire encoder write the id as they write every `UUID`: canonical uppercase.
- Code compares session ids as `UUID` values.

## Metadata file

`<id>.yml` follows the YAML coding, unknown-key and read-modify-write rules of
[project-yml.md](project-yml.md#yaml-coding-all-yaml-files). Keys, in this order:

| Key              | YAML type | Required                  | Written  | Meaning                                                            |
|------------------|-----------|---------------------------|----------|--------------------------------------------------------------------|
| `id`             | string    | yes                       | always   | Session id (a UUID); the id of the file name.                      |
| `kind`           | string    | yes                       | always   | `project`, `task`, `feedback` or `regeneration`.                   |
| `taskID`         | string    | for `task` and `feedback` | when set | Id of the task the session belongs to.                             |
| `mode`           | string    | for `task`                | when set | `implement`, `debug`, `review`, `plan` or `custom`.                |
| `title`          | string    | yes                       | always   | Title shown in the UI and passed to the CLI with `--name`.         |
| `created`        | timestamp | yes                       | always   | Creation time.                                                     |
| `updated`        | timestamp | yes                       | always   | Time of the last write (When it is written).                       |
| `permissionMode` | string    | yes                       | always   | Permission mode of the next process start.                         |
| `model`          | string    | no                        | when set | Model passed with `--model`. Absent: no `--model`.                 |
| `status`         | string    | yes                       | always   | `stopped`, or `failed` when the last process failed (Status).      |

The values are those of `SessionKind`, `SessionMode`, `PermissionMode` and `SessionStatus`
([protocol/types.md](../protocol/types.md)). How a new session gets its title, permission mode and model is defined in
[claude/cli.md](../claude/cli.md).

### Validation and normalization

Applied when a file is read and before a file is written. A file that breaks a rule is invalid; a write that would
break one fails with `.invalid(<message>)`, the message of the table without the file name, and writes nothing. The
rules are checked in the order of the table, so the message is that of the first broken rule.

| Key      | Normalization                                           | Rule                                                                                  | Message                                                  |
|----------|---------------------------------------------------------|---------------------------------------------------------------------------------------|----------------------------------------------------------|
| `id`     | none                                                    | the UUID of the file name                                                             | `id <id> does not match the file name <file name>`       |
| `taskID` | `TaskID(_:)` form                                       | a task id; present for `task` and `feedback`, absent for `project` and `regeneration` | `taskID must be set for task and feedback sessions only` |
| `mode`   | none                                                    | present for `task`, absent for the other kinds                                        | `mode must be set for task sessions only`                |
| `title`  | leading and trailing whitespace and line breaks removed | not empty, no line break                                                              | `the title must not be empty and must be on one line`    |
| `model`  | whitespace trimmed; empty becomes absent                | no line break                                                                         | `model must be on one line`                              |

A title has no maximum length; line breaks are those of
[project-yml.md](project-yml.md#validation-and-normalization).

`kind`, `mode`, `permissionMode` and `status` are checked by decoding (`<key>: invalid value`). The task does not have
to exist: the sessions of a deleted task keep their `taskID` ([task-yml.md](task-yml.md#changes-made-by-the-app)).

### Status

The live statuses `idle`, `starting`, `running` and `waitingPermission` exist only in the memory of `SessionService`.
The file holds `stopped`, or `failed` when the last process failed ([claude/cli.md](../claude/cli.md)). When a file is
read, `SessionFile.decode` reads any value other than `failed` as `stopped`.

### When it is written

`SessionService` writes the file through `SessionArchive`:

- when the session is created;
- when a `user` or a `result` event is appended;
- on each `sessions.update` (title, permission mode, model);
- when a process ends (status `stopped` or `failed`), and when a process cannot be started (status `failed`,
  [claude/cli.md](../claude/cli.md) 5.3).

Each write sets `updated` to `YAMLCoding.now()`.

### Listing

`SessionArchive.list()` reads the files of the `sessions` folder whose name is a lowercase UUID followed by `.yml`:

- A file that cannot be read or is invalid is skipped and logged. The app never writes it; its `.jsonl` and folder stay
  untouched.
- A missing `sessions` folder gives no session.
- The result is sorted by `created`.

### Mapping to SessionInfo

`SessionInfo` ([protocol/types.md](../protocol/types.md)) carries the ten keys of the file under the same names. Its
`status` is the live status while a process exists, else the file's (Status). `statusLine`, `error` and
`pendingPermissions` are kept in memory by `SessionService` and are not stored.

## Event log

`<id>.jsonl` holds the session's `SessionEvent` values in the order they were recorded. This section defines the event
types and their fields; [protocol/types.md](../protocol/types.md) declares the Swift struct, and
[claude/cli.md](../claude/cli.md) maps the CLI output to events.

### Line format

- One event per line: the event encoded with `WireCoding.makeEncoder()`
  ([protocol/envelope.md](../protocol/envelope.md#encoding)), followed by LF. That encoder writes compact JSON with
  sorted keys, dates in ISO 8601 UTC with milliseconds and UUIDs in uppercase. JSON escapes line breaks inside strings,
  so an encoded event holds no LF.
- A line is the same JSON that `session.event` and `sessions.history` carry.

### Event types

Every event has `id`, `at` and `type`, plus the fields of its type. Fields not listed for a type are absent.

| Type                 | Fields                                                                        | Recorded when                                              |
|----------------------|-------------------------------------------------------------------------------|------------------------------------------------------------|
| `user`               | `text`, `attachments`, `deviceID`                                             | a user message is sent to Claude, typed or generated       |
| `assistant`          | `text`, `messageID`, `index`                                                  | Claude finishes a text block                               |
| `thinking`           | `text`, `messageID`, `index`                                                  | Claude finishes a thinking block                           |
| `toolUse`            | `toolUseID`, `name`, `input`, `messageID`, `index`                            | Claude calls a tool                                        |
| `toolResult`         | `toolUseID`, `text`, `isError`                                                | a tool returns                                             |
| `permission`         | `requestID`, `toolName`, `input`, `description`, `suggestions`, `blockedPath` | the CLI asks permission to use a tool                      |
| `permissionDecision` | `requestID`, `decision`, `deviceID`                                           | a permission request is answered or cancelled              |
| `result`             | `isError`, `durationMS`, `costUSD`, `stopReason`                              | a turn ends                                                |
| `system`             | `text`                                                                        | the Main records a notice                                  |
| `error`              | `text`                                                                        | a process fails, or a turn ends with an error              |

### Fields

| Field         | JSON type                 | In                                                               | Meaning                                                                        |
|---------------|---------------------------|------------------------------------------------------------------|--------------------------------------------------------------------------------|
| `id`          | string (UUID)             | every event                                                      | Event id, a new UUID.                                                          |
| `at`          | string (date)             | every event                                                      | When the Main recorded the event.                                              |
| `type`        | string                    | every event                                                      | A `SessionEventType` value: one of the types above.                            |
| `text`        | string                    | `user`, `assistant`, `thinking`, `toolResult`, `system`, `error` | The text (below).                                                              |
| `attachments` | array of `TaskAttachment` | `user`, when not empty                                           | Files saved in `sessions/<id>/` (Attachments).                                 |
| `deviceID`    | string (UUID)             | `user`, `permissionDecision`                                     | Device that sent the message, or whose answer was applied.                     |
| `messageID`   | string                    | `assistant`, `thinking`, `toolUse`                               | Id of the Claude message the block belongs to.                                 |
| `index`       | integer                   | `assistant`, `thinking`, `toolUse`                               | Index of the block in its message, from 0.                                     |
| `toolUseID`   | string                    | `toolUse`, `toolResult`                                          | Id of the tool call (`toolu_…`).                                               |
| `name`        | string                    | `toolUse`                                                        | Tool name.                                                                     |
| `input`       | string                    | `toolUse`, `permission`                                          | Tool input, as compact JSON text.                                              |
| `isError`     | boolean                   | `toolResult`, `result`                                           | The tool or the turn failed.                                                   |
| `requestID`   | string                    | `permission`, `permissionDecision`                               | The CLI's permission request id.                                               |
| `toolName`    | string                    | `permission`                                                     | Tool the CLI asks permission for.                                              |
| `description` | string                    | `permission`, optional                                           | The CLI's description of the call.                                             |
| `suggestions` | string                    | `permission`                                                     | The CLI's permission suggestions, as compact JSON text; `[]` when it has none. |
| `blockedPath` | string                    | `permission`, optional                                           | The path that caused the request.                                              |
| `decision`    | string                    | `permissionDecision`                                             | `allow`, `allowAlways` or `deny` (`PermissionDecision`).                       |
| `durationMS`  | integer                   | `result`                                                         | Duration of the turn in milliseconds.                                          |
| `costUSD`     | number                    | `result`                                                         | Cost of the turn in US dollars.                                                |
| `stopReason`  | string                    | `result`, optional                                               | The CLI's stop reason; absent when it gives none (an interrupted turn).        |

- `text`: for `user`, the text as typed or the generated first message, without the list of attached files that is
  added to the message sent to Claude; for `toolResult`, `system` and `error`, the texts defined in
  [claude/cli.md](../claude/cli.md).
- `messageID` and `index` are the `messageID` and `index` of the block's `session.delta` events
  ([protocol/events.md](../protocol/events.md)): `messageID` is the `message.id` of the CLI's `assistant` line, and
  `index` counts the blocks of that message in the order the CLI writes them ([claude/cli.md](../claude/cli.md)). A
  client replaces the streamed text of the block with the final event ([ui/sessions.md](../ui/sessions.md)).
- `deviceID` of a `user` event is the device whose request produced the message; for a generated first message, the
  device that started the session, which is the Main itself when the MCP tools or the Forge start it. `deviceID` of a
  decision recorded when a pending request is cancelled is the Main's own device id ([claude/cli.md](../claude/cli.md)).
- When a permission request can still be answered, and when the UI shows it as pending, is defined in
  [claude/cli.md](../claude/cli.md) and [ui/sessions.md](../ui/sessions.md).

### Not stored

The `session.delta` fragments, the live status line, the CLI lines that only update the status line, rate limit lines
and unknown lines. The Claude CLI keeps its own transcript under `~/.claude/projects/`; the archive never reads or
changes it.

## Writing events

`SessionArchive.append(_:to:)`:

1. Size limit: a `text` or `input` longer than 65,536 UTF-8 bytes is cut at the last `Character` boundary at or below
   65,536 bytes (the longest prefix of whole `Character`s, grapheme clusters, whose UTF-8 size is at most 65,536
   bytes) and followed by `\n… [truncated: <N> bytes in total]`, `<N>` being its original size in bytes.
2. The event is encoded as one line (Line format).
3. `<id>.jsonl` is opened for reading and writing (`FileHandle(forUpdating:)`), after being created empty when missing.
   When the file is not empty and its last byte is not LF, an LF is written first, so a line cut short by a crash stays
   alone on its line.
4. The line and its LF are written at the end of the file in one write; the file is closed.
5. The function returns the event as stored, after step 1.

- `SessionService` appends an event, then sends the returned value in `session.event`, so live events and history are
  identical.
- Events are never changed or removed; the log grows until the session is deleted.
- Appends are not flushed with `fsync`.

## Reading events

`SessionArchive.history(_:before:limit:)` serves `sessions.history`, one page of the log at a time. The index of an
event is the 0-based position of its line among the non-empty lines of `<id>.jsonl`. Lines are only appended, so an
index never changes.

1. Unknown session (no `<id>.yml`): `.notFound("session <id> not found")`, with the id in canonical uppercase form,
   as in the other messages of this doc that name an id. A session without `<id>.jsonl` has no lines.
2. The file is read whole and split on LF; empty lines are ignored. `total` is the number of the other lines.
3. The page is the lines with an index from `firstIndex` to `end - 1`. `end` is `before`, or `total` when `before` is
   nil or greater than `total`. `firstIndex` is `end - limit`, or 0 when `limit` is nil or `end - limit` is negative.
   A negative `before` or `limit` is read as 0.
4. When `limit` is not nil and the lines of the page add up to more than 16 MiB (16,777,216 bytes, each line counted
   with its LF), its first lines are dropped until the rest fits or one line remains, and `firstIndex` becomes the
   index of the first line kept, so the result fits in a frame. A read with `limit` nil (the search) is not cut.
5. Each line of the page is decoded with `WireCoding.makeDecoder()`. A line that fails (malformed JSON, unknown
   `type`, a field of the wrong type) is skipped and keeps its index; the number of skipped lines is logged once per
   read.
6. The function returns `SessionsHistoryResult` ([protocol/methods.md](../protocol/methods.md#sessionshistory)):
   `events`, the decoded events in file order; `firstIndex`, which is the index of `events[0]` unless that line was
   skipped; `total`.

- `SessionService` passes the request's `before` and `limit` after applying the default limit (1000) and clamping the
  limit to 1…5000, as `sessions.history` says ([protocol/methods.md](../protocol/methods.md#sessionshistory),
  [claude/cli.md](../claude/cli.md)). The search reads every event with `before` and `limit` nil
  ([services/search.md](../services/search.md)).
- A client loads the latest page (no `before`), then each earlier page with `before` = the `firstIndex` of the
  earliest page it holds, while that `firstIndex` is greater than 0 ([ui/sessions.md](../ui/sessions.md)).

A client that subscribes to `session:<id>` and then calls `sessions.history` can receive an event both ways; it keeps
one event per `id` ([ui/sessions.md](../ui/sessions.md)).

## Attachments

The files sent with a message (the `UploadRef` values of `sessions.send`, and of `sessions.start` for the first
message of a project session) are stored in `sessions/<id>/`, created when the first file is stored. They have no size
limit.

- `SessionArchive.saveAttachment(fileAt:originalName:to:)` moves a complete upload
  ([services/files.md](../services/files.md#7-uploads)) into the folder with `FileManager.moveItem(at:to:)`, named with
  `AttachmentNaming.sanitize` and `AttachmentNaming.unique` ([task-yml.md](task-yml.md#naming)), and returns the
  `TaskAttachment` (`file`, `type` from `AttachmentNaming.mimeType`, `size` of the moved file) that goes in the `user`
  event. When the request fails afterwards, `SessionService` moves the stored files back to their uploads
  ([claude/cli.md](../claude/cli.md)).
- `SessionArchive.attachmentURL(_:file:)` is the absolute path that the message sent to Claude gives for the file
  ([claude/cli.md](../claude/cli.md)), and the file that `sessions.readAttachment` reads in ranges.
- Remotes read these files with `sessions.readAttachment`, at most 4 MiB per call
  ([protocol/methods.md](../protocol/methods.md#sessionsreadattachment)), and keep them in their attachment cache
  ([client/workspace.md](../client/workspace.md#transfers)).

## Deletion

`SessionArchive.delete(_:)` serves `sessions.delete`, once `SessionService` has stopped the session's process
([claude/cli.md](../claude/cli.md)):

- It deletes `<id>.yml`, `<id>.jsonl` and the folder `<id>/` with its content; a missing part is ignored.
- When none of the three existed: `.notFound("session <id> not found")`.
- It does not touch `SessionPlugins/<id>/` ([claude/skills.md](../claude/skills.md)) or the CLI's transcript under
  `~/.claude/projects/`.

Deleting a task leaves its sessions in place ([task-yml.md](task-yml.md#changes-made-by-the-app)).

## Logging

`SessionFile` logs with `Log.core`, `SessionArchive` with `Log.host` ([architecture.md](../architecture.md#logging)):
`error` for a skipped metadata file (its name and the `DataError` message) and for skipped event lines (their count),
`fault` for a failed append. Message texts, tool inputs and results are never logged.

## Swift API

`SessionFile` is in HephCore (every platform). `SessionArchive` is in HephHost (macOS only, the file wrapped in
`#if os(macOS)`). The host creates one `SessionArchive` per loaded project, for that project's root, and gives it to
`SessionService`.

```swift
public struct SessionFile: Codable, Sendable, Equatable {
    public var id: UUID
    public var kind: SessionKind
    public var taskID: String?
    public var mode: SessionMode?
    public var title: String
    public var created: Date
    public var updated: Date
    public var permissionMode: PermissionMode
    public var model: String?
    public var status: SessionStatus

    /// The values as given, except `created` and `updated`, which pass through YAMLCoding.wholeSeconds(_:).
    public init(id: UUID, kind: SessionKind, taskID: String?, mode: SessionMode?, title: String, created: Date,
                updated: Date, permissionMode: PermissionMode, model: String?, status: SessionStatus)
    /// .mapping of the ten keys, each .value.
    public static let shape: YAMLShape
    /// id.uuidString.lowercased(): the name of the files and folder, and the CLI session id.
    public static func fileStem(_ id: UUID) -> String
    /// <projectRoot>/.hephaestus/sessions
    public static func folder(projectRoot: URL) -> URL
    /// Decodes, normalizes and validates; `fileName` is "<lowercase id>.yml". A status other than failed is read as
    /// stopped (Status).
    public static func decode(_ text: String, fileName: String) throws -> SessionFile
    public func encode(preserving previousText: String?) throws -> String
    public mutating func normalize()
    public func validate(fileName: String) throws
}

public actor SessionArchive {
    public nonisolated let projectRoot: URL
    public init(projectRoot: URL)

    /// Every valid metadata file, `status` read as in Status, sorted by created.
    public func list() -> [SessionFile]
    public func load(_ id: UUID) throws -> SessionFile
    /// Writes a new <id>.yml; .invalid("<lowercase id>.yml already exists") when it exists.
    public func create(_ file: SessionFile) throws
    /// Read-modify-write of <id>.yml; sets `updated`; returns the file as written.
    @discardableResult
    public func update(_ id: UUID, _ change: @Sendable (inout SessionFile) throws -> Void) throws -> SessionFile

    /// Applies the size limit, appends one line, returns the event as stored.
    public func append(_ event: SessionEvent, to id: UUID) throws -> SessionEvent
    /// One page of the log (Reading events); nil `before` and `limit`: every event, without the 16 MiB cut.
    public func history(_ id: UUID, before: Int?, limit: Int?) throws -> SessionsHistoryResult

    /// Moves the file at `fileAt` (a complete upload) into <id>/ (Attachments).
    public func saveAttachment(fileAt: URL, originalName: String, to id: UUID) throws -> TaskAttachment
    public nonisolated func attachmentURL(_ id: UUID, file: String) -> URL

    public func delete(_ id: UUID) throws
}
```

`SessionKind`, `SessionMode`, `SessionStatus`, `PermissionMode`, `PermissionDecision`, `SessionInfo`, `SessionEvent`,
`SessionEventType`, `TaskAttachment` and `UploadRef` are defined in [protocol/types.md](../protocol/types.md);
`SessionsHistoryResult` in [protocol/methods.md](../protocol/methods.md#sessionshistory); `DataError` and `AtomicFile`
in [app-storage.md](app-storage.md); `YAMLShape` and `YAMLCoding` in [project-yml.md](project-yml.md).
